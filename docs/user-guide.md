# Посібник користувача CafeOrders

Для касира кав’ярні. Програма працює в консолі; кожна дія — це номер команди та кілька
відповідей на запитання.

## Запуск

```
dotnet run --project CafeOrders.App
```

Після запуску програма показує версію, кількість позицій меню й уже збережених замовлень:

```
CafeOrders v0.8.0
Каса кав’ярні: меню 57 позицій і 4 комплекси, замовлень 0
```

Замовлення зберігаються у файлі `data/orders.local.json` у поточній теці й відновлюються
під час наступного запуску. Журнал подій — `data/cafe.local.log`.

## Команди

| Команда | Дія | Що запитає програма |
|---|---|---|
| 1 | Відкрити замовлення | номер гостя; чи за столиком (так/ні) |
| 2 | Додати позицію або комплекс | номер замовлення; код; кількість |
| 3 | Передати на кухню | номер замовлення |
| 4 | Позначити, що страви подано | номер замовлення |
| 5 | Рахунок і оплата | номер замовлення; внесену суму |
| 6 | Скасувати замовлення | номер замовлення |
| 7 | Пошук | стан (або Enter — будь-який); номер гостя (або Enter) |
| 8 | Звіт «популярність позицій» | — |
| 9 | Показати меню | — |
| 0 | Вийти | — |

Код позиції можна вводити малими літерами: `cap-001` і `CAP-001` — те саме.
Суму вводьте з крапкою: `400.00`.

## Типовий сеанс

Фрагменти реального запуску (повний вивід — у звіті СР3).

**Відкрити замовлення для гостя за столиком і додати каву:**

```
> 1
Номер гостя: 7
За столиком (так/ні): так
Відкрито замовлення 1
> 2
Номер замовлення: 1
Код позиції: cap-001
Кількість: 2
Додано: CAP-001 x 2 = 130.00 грн
```

**Помилка вводу — програма просить повторити:**

```
Кількість: два
Помилка вводу: потрібне ціле число більше 0
Кількість: 2
Додано: CMB-001 x 2 = 210.00 грн
```

**Позиція в стоп-листі:**

```
Код позиції: TEA-005
Кількість: 1
Відхилено: Матча лате зараз недоступна
```

**Закрити рахунок.** За столиком додається сервісний збір 5 %; від 1000 грн — ще 10 %,
але не більше 150 грн. Якщо внесено замало, рахунок лишається відкритим — повторіть
команду 5:

```
> 5
Номер замовлення: 1
Страви 340.00, сервісний збір 17.00, разом 357.00 грн
Внесено: 300
Відхилено: Внесено 300.00, треба 357.00
> 5
Номер замовлення: 1
Страви 340.00, сервісний збір 17.00, разом 357.00 грн
Внесено: 400.00
Рахунок закрито, решта 43.00 грн
```

**Звіт популярності** (лише оплачені замовлення):

```
> 8
Код         Порцій      Виторг
CAP-001          2      130.00
CMB-001          2      210.00
```

## Порядок роботи із замовленням

Нове → (3) на кухні → (4) подано → (5) оплачено. Додавати позиції можна лише до нового
замовлення. Скасувати (6) можна, поки страви не подано.

## Повідомлення «Відхилено»

| Повідомлення | Причина | Що робити |
|---|---|---|
| Замовлення N не знайдено | Неправильний номер | Знайдіть номер командою 7 |
| Додавати позиції можна лише до нового замовлення | Замовлення вже на кухні | Відкрийте нове замовлення |
| … зараз недоступна | Позиція в стоп-листі | Запропонуйте іншу позицію (команда 9) |
| Позиції … немає в меню | Помилка в коді | Перевірте код у меню (команда 9) |
| Закрити можна лише поданий рахунок | Страви ще не подано | Спершу команда 4 |
| Внесено X, треба Y | Сума менша за підсумок | Повторіть команду 5 з більшою сумою |
| Замовлення у стані … скасувати не можна | Страви вже подано | Скасування неможливе, закрийте рахунок |

## Дані та резервна копія

| Файл | Що містить |
|---|---|
| `data/menu.json` (поруч із програмою) | Меню, комплекси, стоп-лист; змінює адміністратор |
| `data/orders.local.json` (у теці запуску) | Усі замовлення з рядками й станами |
| `data/cafe.local.log` (у теці запуску) | Журнал дій каси |

Резервна копія — це копія файлу замовлень, зроблена, коли програму закрито (команда 0):

```
copy data\orders.local.json backup\orders-2026-11-14.json
```

Щоб відновити дані, закрийте програму й скопіюйте файл назад під ім’ям `orders.local.json`.

## Якщо щось пішло не так

- Програма одразу після запуску пише «Непередбачений збій» і завершується — найчастіше
  пошкоджено файл замовлень. Збережіть копію `data/orders.local.json` і видаліть файл;
  програма почне з порожнього списку.
- Подробиці кожної дії — у `data/cafe.local.log` (рядки з `Warning` — відмови).
